## Guidelines for Running in Cloud Environments

If you wish to execute any of these workflows:
1. Upload the target notebook to Kaggle or Google Colab with a GPU runtime (T4, P100, or A100).
2. Install development dependencies: `pip install -r requirements-dev.txt`.
3. Provide real, non-leaked data from `data/splits/train.jsonl.gz`.
4. Execute all cells sequentially from top to bottom; results must always come from executed cells.
