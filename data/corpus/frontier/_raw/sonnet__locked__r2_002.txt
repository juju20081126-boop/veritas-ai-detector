=== prompt_id: gene-0477 ===
Use semantic `<section>` elements, give each one a unique `id`, and build a `<nav>` list whose links point to those ids with `#`.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
  <style>
    html { scroll-behavior: smooth; }
  </style>
</head>
<body>
  <h1 id="top">My Page</h1>

  <nav aria-label="Table of contents">
    <h2>Contents</h2>
    <ol>
      <li><a href="#intro">Introduction</a></li>
      <li><a href="#methods">Methods</a></li>
      <li><a href="#results">Results</a></li>
    </ol>
  </nav>

  <section id="intro">
    <h2>Introduction</h2>
    <p>Your text here.</p>
    <a href="#top">Back to top</a>
  </section>

  <section id="methods">
    <h2>Methods</h2>
    <p>Your text here.</p>
    <a href="#top">Back to top</a>
  </section>

  <section id="results">
    <h2>Results</h2>
    <p>Your text here.</p>
    <a href="#top">Back to top</a>
  </section>
</body>
</html>
```

**How it works**

- A link with `href="#methods"` scrolls the browser to the element whose `id` is `methods`.
- `<nav>` tells browsers and screen readers that the block is for navigation.
- `<ol>` gives numbered entries. Switch to `<ul>` for bullets, or nest lists for subsections.
- `scroll-behavior: smooth` animates the jump instead of snapping.

**Tips**

- Keep ids lowercase, free of spaces, and unique within the page.
- To keep the table of contents visible while scrolling, add `position: sticky; top: 1rem;` to the `nav` element.
- For long documents, a short script can build the list automatically from your headings.

=== prompt_id: abst-0118 ===
Quantifying how information is distributed across the parts of a multivariate system remains an open problem in information theory and its applications in neuroscience, complex systems, and machine learning. The recently proposed Partial Information Decomposition (PID) addresses part of this problem by splitting the mutual information that a set of predictor variables carries about a target into redundant, unique, and synergistic contributions, but it requires one variable to be singled out as the target and offers no account of how the entropy of the system itself is organized. Here we apply the PID formalism to entropy rather than mutual information, introducing the Partial Entropy Decomposition (PED). The PED treats the joint entropy of a set of variables symmetrically and partitions it into non-overlapping atoms that capture the entropy shared redundantly by different combinations of variables, as well as the entropy that is unique to, or synergistically distributed across, them. To make the decomposition operational, we define redundant entropy through pointwise common surprisal, the portion of surprisal that individual outcomes of different variables have in common. This definition is closely related to the pointwise formulation of mutual information, and it allows both entropy and mutual information to be written as sums over the same set of atoms. We examine the properties of the resulting measure, show how it recovers familiar quantities, and demonstrate its behavior on canonical examples such as logic gates and simple discrete systems. We also discuss how the atoms relate to multivariate quantities such as co-information, and note that the results depend on the choice of redundancy measure. The PED provides a target-free decomposition that complements the PID and offers a new route to analyzing statistical dependence in multivariate data.
